## Selected Case Study: E-Commerce Platform

### Organisation Name
**ShopEase** — An online retail e-commerce platform.

### Nature of the Business/System
ShopEase is a B2C (Business-to-Consumer) e-commerce platform that allows customers to browse products, place orders, make payments, and track deliveries. Vendors can list products, manage inventory, and view sales reports. The platform handles thousands of transactions daily across multiple product categories.

### Users of the Database
| User Type | Role |
|-----------|------|
| Customers | Browse products, place orders, make payments, track deliveries |
| Vendors/Sellers | List products, manage stock, view orders |
| Admins | Manage users, resolve disputes, generate reports |
| Delivery Agents | Update delivery status |

### Major Data to be Stored
- Customer profiles and authentication details
- Product catalogue (names, descriptions, prices, categories, attributes)
- Inventory and stock levels
- Orders and order line items
- Payments and transaction logs
- Delivery records and status tracking
- Reviews and ratings
- Vendor/seller accounts

### Key Operations the Database Will Support
- User registration and authentication
- Product search, filtering, and browsing
- Adding products to cart and placing orders
- Processing payments and recording transactions
- Updating stock levels on purchase
- Tracking delivery status
- Posting and retrieving product reviews
- Generating sales and inventory reports
